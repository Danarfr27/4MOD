# AIVOLKS - AI Dashboard

A modern, dark-themed landing page for AIVOLKS AI Dashboard built with React, TypeScript, and Tailwind CSS.

## Features

- **Particle Animation Background** - Interactive canvas with connecting particles
- **Responsive Design** - Works on all screen sizes
- **Scroll Animations** - Intersection Observer based reveal animations
- **Dark Theme** - Sleek black and orange color scheme
- **Modern Stack** - React 19 + TypeScript + Vite + Tailwind CSS

## Tech Stack

- React 19
- TypeScript
- Vite 7
- Tailwind CSS 3.4
- Lucide React (icons)

## Getting Started

### Prerequisites

- Node.js 20+
- npm or yarn

### Local Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

### Deploy to Vercel

#### Option 1: GitHub + Vercel (Recommended)

1. **Create GitHub Repository**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/aivolks-dashboard.git
   git push -u origin main
   ```

2. **Connect to Vercel**
   - Go to [vercel.com](https://vercel.com)
   - Sign up / Log in with your GitHub account
   - Click "Add New Project"
   - Import your GitHub repository
   - Vercel auto-detects Vite + React
   - Click **Deploy**

3. **Done!** Your site will be live at `https://aivolks-dashboard.vercel.app`

#### Option 2: Vercel CLI

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

#### Option 3: Manual Upload

1. Run `npm run build`
2. Go to [vercel.com](https://vercel.com)
3. Drag and drop the `dist/` folder

### Vercel Configuration

The `vite.config.ts` and `vercel.json` (auto-generated by Vercel) handle routing. No extra config needed.

## Customization

- Edit `tailwind.config.js` to change colors and theme
- Modify `src/pages/Landing.tsx` to update content
- Adjust particle count in `src/components/ParticleField.tsx`
